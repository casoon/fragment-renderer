## Requirements

| Requirement | Version |
| --- | --- |
| Node.js | `>= 18.0.0` |
| Astro (peer dependency) | `>= 4.0.0` |
| Module format | ES modules only (`"type": "module"`) |

The package ships TypeScript declarations. Its repository is built with TypeScript strict mode and
developed against Astro 6.

<Callout type="caution">
The runtime is built on Astro's `experimental_AstroContainer`. The name says it: Astro may change
that API between versions. The wrapper in `src/internal/container.ts` is the one place that
touches it.
</Callout>
